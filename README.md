# TRX能量出租平台

一个现代化、专业的TRX能量租赁网站，提供高效、安全、实惠的TRON能量租赁服务。

## 🌟 功能特色

### 核心功能
- **能量租赁服务** - 支持多种套餐选择，满足不同用户需求
- **实时价格计算** - 智能计算租赁费用，支持自定义能量数量和时长
- **钱包连接** - 支持TronLink钱包连接，安全便捷
- **资源类型选择** - 支持能量(Energy)和带宽(Bandwidth)租赁
- **响应式设计** - 完美适配桌面端和移动端设备

### 租赁套餐
1. **基础套餐** - 32,000 能量 / 3.2 TRX per day
2. **标准套餐** - 65,000 能量 / 6.5 TRX per day  
3. **高级套餐** - 130,000 能量 / 12 TRX per day

### 技术特点
- **现代化UI设计** - 采用渐变背景、毛玻璃效果和流畅动画
- **交互体验优化** - 平滑滚动、悬停效果和实时反馈
- **安全保障** - 地址验证、钱包连接状态检查
- **性能优化** - 轻量级代码、快速加载

## 🚀 快速开始

### 1. 直接访问
直接在浏览器中打开 `index.html` 文件即可使用。

### 2. 本地服务器（推荐）
```bash
# 使用Python简单服务器
python -m http.server 8000

# 或使用Node.js
npx http-server

# 然后访问 http://localhost:8000
```

### 3. 部署到服务器
将项目文件上传到任何支持静态文件的服务器即可。

## 📱 使用说明

### 连接钱包
1. 点击右上角"连接钱包"按钮
2. 确保已安装TronLink钱包插件
3. 授权连接后即可使用租赁功能

### 租赁流程
1. **选择套餐** - 点击预设套餐或自定义配置
2. **填写信息** - 输入能量数量、租赁时长和接收地址
3. **查看费用** - 系统自动计算总费用
4. **提交订单** - 确认信息后提交租赁请求

### 计算器使用
- **能量数量**: 输入所需的能量单位（最少1000）
- **租赁时长**: 选择1-30天的租赁期限
- **接收地址**: 输入有效的TRON地址（T开头，34位）
- **资源类型**: 选择能量或带宽
